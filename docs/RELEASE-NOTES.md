# Session Desk 0.3.1

Regular Windows x64 release.

- Drag Resources tabs to arrange source books and prepared maps. Use Alt+Left or Alt+Right to move a focused tab. The order is saved in the workspace and included in its backup.
- Prepared maps can open the exact keyed room entry from your connected local 5e.tools library. The room panel also shows available DM prep, narration and encounters. Drag the divider to give the room more space.
- Prepared maps open on the standard player screen with tabs, zoom and drawing. Choosing a room keeps its existing fog state.
- A local collection of authored encounters can be imported as a separate source. Standalone maps can be presented with fog.

Use Settings → Check for updates → Download and install → Restart into update. Keep using your existing workspace and connected source library. Private hosting follows the updated app when it restarts.
