# Session Desk 0.3.2

Regular Windows x64 release.

- One Player Screen keeps tabs from across a workspace. Present a map or image from another source and switch between open tabs on the same screen.
- A workspace can group its editable journal, authored sources, and restored maps in one campaign book. Reference books remain available from Resources.
- Prepared map navigation keeps the sidebar open at its current position. Scroll down to make room for the content and scroll up to bring the headers back.
- The local workspace opens while a configured Tailscale connection comes online. Quit stops the app and its private Serve endpoint.

Use Settings → Check for updates → Download and install → Restart into update. Existing workspace backups, map fog and notes carry forward.
