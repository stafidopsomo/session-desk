SESSION DESK 0.1.0-preview.1 — WINDOWS X64 PREVIEW

Have a supported prepared-campaign or Session Desk backup? Choose Restore
backup on the home screen. A new workspace is created; your original stays
untouched. Open prepared campaign appears only when imported content exists.
Connect your local 2014 library for its book/rules references. Export backup
includes edited characters, stories, maps/fog, pictures and original files.
On another computer, restore that ZIP and reconnect its local rules library.
Scripts in backups are retained as files only; AI/generation stays Off.

1. Extract the entire ZIP into a folder you can keep.
2. Run SessionDesk.exe. Keep the _internal folder beside it.
3. Create a workspace and choose Add adventure. Use existing copy validates
   the folder and shows which adventure files and images were found.
   Install local copy downloads a verified 2014 source release to a new or
   empty folder you choose. Optional adventure images download during import
   for that installed copy; this is not the complete image archive.
   No books or pictures are bundled in the Session Desk ZIP.
4. Read import warnings. Review images for secrets before marking them safe
   to share. Source room boundaries can be used directly. If one is wrong,
   select the room, choose Draw boundary, drag around its complete edge and
   Save boundary. There are no coordinate fields or verification steps.
   Selecting or reading an entry/room never reveals it.
5. Resources is the single adventure browser. Expand chapter arrows or
   search; filter by Text, Images or Maps. Collapse all clears filters and
   returns to closed chapters. Pin resources to keep them above search.
   Choosing text opens its book reader and narration/private-notes form;
   choosing an image/map opens its preview. Room source/preparation stays
   beside the map. Selecting resources does not share them automatically.
   Present sends reviewed media to the player screen. On player screen
   lists the shared tabs, which either window can select or close. Player
   zoom, temporary drawing and shared notes work on the same computer/TV.
   Reveal/Hide have a brush circle matching the size slider and map zoom.
   Space temporarily switches to pan; the circle disappears while panning.

If upgrading an older imported adventure, import that same adventure once
more to add its original book structure. Notes, pins, manually drawn edges,
custom pictures and the existing session/fog are preserved.

Your workspaces are saved in %LOCALAPPDATA%\SessionDesk\workspaces,
outside this application folder. Export a workspace backup before moving
computers. Restore backup creates a separate workspace with its pictures.
Export and restore show progress and can be cancelled before the final
commit. Restores validate their files before the new workspace appears.
An interrupted transfer can be retried with the original ZIP; saved
workspaces remain intact. Private transfer cache is cleared at shutdown
or recovered on the next launch. Backups support up to 1 GB plus metadata
(metadata maximum 64 MB).

If an imported source image is missing or damaged, re-import that same
adventure from the complete original library. This repairs source images
without resetting your notes, pinned resources or session/fog.

Settings (top right) contains Display and the unavailable AI control.
AI is Off: there is no provider setup, generation or account connection.
Closing the last DM/player tab stops the app after about 8 seconds, allowing
time for reloads. Keep either window open while playing. Settings > Quit app
stops it immediately. If a browser crashes without sending a close event,
the lost-window timeout is about 100 seconds. This releases the EXE so its
folder can be moved/deleted; workspace data remains outside that folder.

This is an unsigned public preview prerelease, not a completed alpha.
Do not disable Windows protections to run it. If the publisher is untrusted
to you, wait for a trusted/signed distribution. Windows 11 x64 is the initial
validation target. Laptop/friend-PC compatibility and full visual review of
every source map remain pending. Automated tests do not establish those results.
No developer tools, Python, Node, Git or AI login are needed to run the EXE.

Limitations: structured local library import only, no PDF/OCR, no automatic
geometry inference, no remote/LAN mode. Restore also accepts supported prepared-campaign recovery ZIPs.
Changed source snapshots must be imported into a new workspace to preserve
existing preparation. Backup ZIPs contain your imported source content;
keep them private. Temporary drawings are not saved. Native folder selection
is optional; pasting the folder path works as well.
