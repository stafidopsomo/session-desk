SESSION DESK 0.2.2 — WINDOWS X64

1. Extract the entire application ZIP. Keep _internal beside SessionDesk.exe.
2. Double-click SessionDesk.exe. No Python, Git, Node or AI account is needed.
3. Create a workspace: Campaign starts with Book; One-shot / standalone session
   starts with Resources and has no Book section.
4. Choose Add adventure. Select your local 5e.tools library or explicitly
   install the supported local 2014 copy. Search titles, choose and import.
5. Prepare your resources, then Present and Open player screen for the TV.
   Map/room inspection is private. Reveal room or the brush changes fog.

BOOK (Campaign workspaces): write session records, preparation and missions. Choose Edit, then Save.
Mission offers, outcomes and rewards awarded are separate. A conflicting save
keeps your draft; copy it before choosing Reload saved record.
PARTY: edit concepts and private notes. Restored characters keep their complete
mechanical sheets under Open full sheet; this still opens the compatibility
editor. It does not award levels, powers, membership, money or rewards.
RESOURCES: imported books retain their reader, search, pins, room preparation
and boundary correction. Restored maps keep their original geometry and fog.
Use All sources to switch adventures. Ordinary browser tabs can show different
characters, entries and maps; inspecting them does not change the TV.

ALREADY USING SESSION DESK?
Use Settings > Check for updates > Download and install > Restart into update.
The regular app uses %LOCALAPPDATA%\SessionDesk, preserving existing workspaces.
The new Book is added non-destructively; original authored files remain intact.
Export backup before upgrading or moving computers. Restore creates a separate
workspace with its assets, Book, missions, character records and saved fog.
Reconnect your local source library on a different computer.

A previous --preview launch uses SessionDesk-CampaignPreview instead. That
profile and its edits stay separate; the regular release does not merge them.

Pictures, books, campaigns and credentials are not bundled. AI is Off and
unavailable. Homebrew-JSON, PDF/OCR and remote/LAN imports/players are not
implemented. Full cross-source presentation, scene-card migration and advanced
Party integration remain future work. The package is unsigned; actual laptop
and friend-PC compatibility and universal map geometry are not certified.

Closing the last app window shuts down its local server after a short grace
period. Do not delete your workspace folder when replacing application files.
